# Introduction_project6677
Проверка на Анаграмму (Python)

Этот проект содержит простую программу на Python, которая проверяет, являются ли две введенные строки анаграммами друг друга.

 Описание
Анаграмм — это слова или фразы, которые состоят из одних и тех же букв в разном порядке. Например, "сон" и "нос".

Программа выполняет следующие действия:
1. Принимает две строки от пользователя.
2. Удаляет лишние пробелы и переводит всё в нижний регистр.
3. Сортирует буквы в обеих строках.
4. Сравнивает результат и сообщает, являются ли строки анаграммами.

Как запускать
Для запуска программы вам понадобится установленный Python 3.

1. Склонируйте репозиторий или просто скачайте файл `Anagram.py`.
2. Откройте терминал (или командную строку).
3. Запустите файл командой:
   ```bash
   python Anagram.py
